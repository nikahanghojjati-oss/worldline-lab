# Worldline Lab · Product and Research Roadmap
Updated 2026-10-21

## Release 0.1 · Published foundation (verified)
Public URL: https://nikahanghojjati-oss.github.io/worldline-lab/
GitHub Pages run: https://github.com/nikahanghojjati-oss/worldline-lab/actions/runs/39696764814
The research journal, compass, source-ledger filtering, multidisciplinary lab index, stylized interactive Earth and solar-atlas selectors, and measured-only session registry are live site features.
The atlas is a stylized diagram. A true geographic projection or 3D globe has NOT been implemented; no experiment locations should be inferred from its illustration.

## Release 0.2 · Truth Engine (next)
- Introduce a schema and test runner validating source URLs, type, timestamps, unique IDs, geographic precision and dependent citations.
- Require a claim classification, counter-evidence search and an auditable impact rationale for every proposed meter change.
- Add a versioned change ledger, with each change linking the commit SHA and prior judgment.
- Distinguish weighted research priority from empirical probability. Do not use evidence of time dilation to award many-worlds proof.
- Acceptance: any score revision can be traced to its underlying reviewed data and reversible scientific argument.

## Release 0.3 · Atlas and provenance
- Add an accessible, zoomable 2D geographic map showing the institution, experiment site, observation instrument and publication location as separate spatial fields.
- Add a 3D Earth globe progressively, only with verified coordinates and clear source attribution; preserve a usable 2D fallback on mobile.
- Extend the solar atlas with celestial observations only where primary references provide real measurement provenance.
- Acceptance: each marker links to an exact ledger record, with metadata explaining coordinate precision. No unsourced dots.

## Release 0.4 · Deep discipline rooms
- Physics: timeline model explorer and causal diagrams.
- Quantum: interactive measurement thought experiments, with careful interpretation warnings.
- Mathematics: consistency proof gallery and model assumptions.
- AI / computer science: source provenance, graph-based claim dependencies and scenario testing.
- Chemistry and biology: coherence, clocks, constraints, relevance assessment.
- Neuroscience: subjective versus physical time; historical science context.
- History: source criticism, counterfactual constraints and epistemology of records.
- Acceptance: each room has at least one cited tutorial, one research question and a clear limitation.

## Release 0.5 · Sessions and continuity
- Add per-study work packets: exact objective, source digest, unresolved contradictions, next falsifiable action and review gate.
- Record instrumented usage only when supplied by reliable session tools; otherwise show N/A.
- Make state transitions READY / STALE / BLOCKED evidence-based, not arbitrary duration estimates.
- Add concise machine-readable checkpoints. Do not create a factory of agents.
- Acceptance: fresh chat can resume from SESSION_START.md plus a few narrowly selected JSON files.

## Release 0.6 · Recurring research and public science review
- Agree on recurrence and monitoring scope with owner before creating a scheduled task.
- Record regular literature scans and source changes as candidate evidence, never automatically as established truth.
- Propose a human-review threshold for changing the compass and retaining dissenting interpretations.
- Acceptance: an immutable record shows what was searched, when, and why conclusions did or did not change.
