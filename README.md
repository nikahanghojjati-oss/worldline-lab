# Worldline Lab

An open, evidence-driven research publication on time, causality, and the possibility of one or multiple physically realized histories.

Public site: https://nikahanghojjati-oss.github.io/worldline-lab/

## Published sections

The magazine-style front page features the Truth Compass. The navigation opens Observatory, Truth Ledger, Journal, Research Labs, Origins Atlas, Scholar Library, and Session Observatory. The atlas includes an interactive conceptual globe and solar-system navigator, with careful labeling of what is and is not geographically sourced.

## Current scientific status

The answer is unresolved. The provisional 59/100 compass is an **editorial orientation inherited from the founding conversation, not a probability** or verified result. ## Source of truth

- `data/ledger.json` — citable evidence with provenance, grade, limitation and explicit compass impact.
- `data/research.json` — research roadmap, field lanes, first journal issue.
- `data/library.json` — versioned bibliography and profiles of contributing scholars, with distinct review stages and linked verdict history.
- `data/reading-notes.json` — section-aware, auditable per-source study notes and limitations.
- `LIBRARY_PROTOCOL.md` — governance, evidence impact requirements, and counted reading completion.
- `research/field-note-001.md` — first source-annotated synthesis of one-history and many-history claims.
- `data/sessions.json` — compact session history, blocker, continuity and the next verified research action.
- `RESEARCH_PROTOCOL.md` — scientific admission rules.
- `SESSION_START.md` — compact continuation guide for a fresh ChatGPT session.
- `index.html` and `assets/` — static public site rendered by GitHub Pages.

## Continuity and safety

GitHub Pages serves read-only public JSON. Visitor actions on the website do not write to GitHub, and GitHub secrets are never exposed in browser code. To publish reviewed changes, change source JSON in a GitHub commit; the website then loads the updated content. The session view tracks milestone completion, continuity risks, and minimal truthful handoffs.

## Publication

Configure GitHub Settings → Pages → Deploy from a branch → `main` → `/(root)`. GitHub Pages deploys the site after the next successful build. The repository remains independent of Career Mode Showdown.

The public Session page shows a four-condition restart-packet meter, a clear Continue / Prepare / Transition recommendation, the newest public GitHub commits from across the project, and a workstream report backed by `data/sessions.json`.
