# Worldline Lab

An open, evidence-driven research publication on time, causality, and the possibility of one or multiple physically realized histories.

Public site: https://nikahanghojjati-oss.github.io/worldline-lab/

## Published sections

The magazine-style front page features the Truth Compass. The navigation opens Observatory, Truth Ledger, Journal, Research Labs, Origins Atlas, and Session Registry. The atlas includes an interactive conceptual globe and solar-system navigator, with careful labeling of what is and is not geographically sourced.

## Current scientific status

The answer is unresolved. The provisional 59/100 compass is an **editorial orientation inherited from the founding conversation, not a probability** or verified result. Evidence is categorized before relevance is evaluated. No amount of simulated closed timelike curve behavior on its own proves time travel or branching histories.

## Source of truth

- `data/ledger.json` — citable evidence with provenance, grade, limitation and explicit compass impact.
- `data/research.json` — research roadmap, field lanes, first journal issue.
- `data/sessions.json` — compact session history, blocker, continuity and any legitimately measured usage.
- `RESEARCH_PROTOCOL.md` — scientific admission rules.
- `SESSION_START.md` — compact continuation guide for a fresh ChatGPT session.
- `index.html` and `assets/` — static public site rendered by GitHub Pages.

## Continuity and safety

GitHub Pages serves read-only public JSON. Visitor actions on the website do not write to GitHub, and GitHub secrets are never exposed in browser code. To publish reviewed changes, change source JSON in a GitHub commit; the website then loads the updated content. The session page reports unknown token usage and context as N/A rather than estimating.

## Publication

Configure GitHub Settings → Pages → Deploy from a branch → `main` → `/(root)`. GitHub Pages deploys the site after the next successful build. The repository remains independent of Career Mode Showdown.
