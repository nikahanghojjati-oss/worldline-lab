# Worldline Lab · Research Protocol

Version: 0.1 · 2026-10-21

## Central question
What observations, if any, can distinguish a universe with one physically realized history from a universe with multiple histories?

## Evidence gate
1. Record a stable source URL, publication identity, retrieval date and primary claim.
2. Tag each entry experiment, observation, theoretical model, interpretation, simulation or thought experiment.
3. Separate direct measurement from inference. A model of a closed timelike curve is not an observed time machine.
4. Identify whether the result is *discriminating* between hypotheses. Nondiscriminating evidence receives zero meter movement.
5. Cluster correlated claims from the same study so they cannot be counted multiple times as independent proof.
6. Document uncertainties, contradictory findings, limitations and disconfirming possibilities.
7. Never silently rewrite older judgments; log changed classifications with a reason and immutable commit record.

## Compass
The displayed 59/100 is an editorial exploratory orientation inherited from the planning conversation, **not** a Bayesian probability or a claim that the many-worlds interpretation is confirmed. The empirical verdict remains unresolved. The compass is a navigation tool; it is not a measurement instrument.

## Session continuity
The project uses repository-backed state files, one active question per study cycle, a verified evidence boundary, and an explicit next action. Token/time/context metrics remain unknown unless supplied by a legitimate instrumentation source; never estimate them as though measured. Continue by reading `data/sessions.json`, then `data/research.json`, and then relevant portions of `data/ledger.json`.

## Research loop
OBSERVE → MODEL → HYPOTHESIZE → PLAN → STUDY → VERIFY → LEARN → PRESERVE. Scientific progress requires an accepted evidence unit, not additional process documentation. If a proposed line of inquiry fails twice without new evidence, reformulate the question.

## Origin atlas
Map coordinates denote a broadly associated institution for cited studies where available. They are not experiment geotags; purely theoretical entries have no invented geographic coordinates. Solar-system markers are conceptual navigation, not evidence from celestial locations.

## Public site
GitHub Pages publishes from `main` root. The browser site is read-only against the canonical research JSON; no GitHub token is shipped to browsers. Publications must be committed to the repository.
