# Worldline Lab · Research Protocol

Version: 0.1 · 2026-10-21

## Central question
What observations, if any, can distinguish a universe with one physically realized history from a universe with multiple histories?

## Evidence gate
1. Record a stable source URL, publication identity, retrieval date and primary claim.
2. Tag each entry experiment, observation, theoretical model, interpretation, simulation or thought experiment.
3. Separate direct measurement from inference. A model of a closed timelike curve is not an observed time machine.
4. Identify whether the result is *discriminating* between hypotheses. Nondiscriminating evidence receives zero meter movement.
5. Cluster correlated claims from the same study so they cannot be counted multiple times as independent proof.
6. Document uncertainties, contradictory findings, limitations and disconfirming possibilities.
7. Never silently rewrite older judgments; log changed classifications with a reason and immutable commit record.

## Research loop
OBSERVE → MODEL → HYPOTHESIZE → PLAN → STUDY → VERIFY → LEARN → PRESERVE. Scientific progress requires an accepted evidence unit, not additional process documentation. If a proposed line of inquiry fails twice without new evidence, reformulate the question.

## Origin atlas
Map coordinates denote a broadly associated institution for cited studies where available. They are not experiment geotags; purely theoretical entries have no invented geographic coordinates. Solar-system markers are conceptual navigation, not evidence from celestial locations.

## Public site
GitHub Pages publishes from `main` root. The browser site is read-only against the canonical research JSON; no GitHub token is shipped to browsers. Publications must be committed to the repository.

## Primary question — owner-approved 2026-10-21
**Does the physical universe inhabited by human observers contain one physically realized history or multiple physically real timelines/branches?** This question supersedes the time-travel-first framing. Treat Everettian quantum branches, Bohmian definite particle histories, objective-collapse models, cosmological inflationary bubbles, and a person's one observed record as carefully separated claims. Backward travel, CTCs and grandfather paradoxes remain supporting questions, not prerequisites. Scientific verdict shifts require model-specific, independently attributable, discriminating observations; never count Bell violations, decoherence, simulations or cosmological bubbles as direct branch observations. Preserve all previously planned labs, atlas, library and sessions, 75% research/25% website priority, truthful source depth and mandatory every-round Session Observatory closure. The next research body should build a quantitative predictions matrix; see research/field-note-004.md and audit VC-006.

## Two-track movement: scientific results and main ontology
1. Update the status of each falsifiable physical model when measurements exclude parameter regions, narrow bounds, demonstrate an effect or expose a false assumption. Include prior state, measured quantity, uncertainty, model assumptions, competing effects, source and next falsifiable action.
2. Strict Everett and equilibrium Bohm can assign different ontologies to the same Born distributions. Under identical test predictions, these data cannot numerically distinguish how many physically real histories exist; report the precise identifiability obstruction rather than claiming no research progress.
3. A central directional compass change requires a defensible difference between the single-real-history and multiple-real-history model predictions plus evidence and a justified mapping to the editorial number. The display's neutral 50 is not a prior probability.
4. Source reading is an input to a research question. Every review should say what physical hypothesis was tested, which candidates survived/failed, what likelihood or limit was learned, and the next discriminating experiment.
5. See WL-011 / MOVE-001 in data/ledger.json and research/score-origin-and-testable-results-S002-R005.md. Do not automatically count multiple outputs from the same experimental dataset as independent findings.
