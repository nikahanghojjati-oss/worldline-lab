What would justify a central Truth Compass change? Predict different records →
  1. Specify both ontologies with physical dynamics and compatible instruments.
  2. Predict different records using source-derived likelihoods, not imagined parameters.
  3. Test the world using measured, calibrated data and alternative explanations.
  4. Reproduce and critique source code and real AI model reviews when actually run.
  5. Publish the change with explicit provenance and reasons it could reverse.
